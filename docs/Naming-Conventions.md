# Naming Conventions

Use names that are stable, descriptive, and easy to locate.

- Organization folders beneath `agents/` use **PascalCase** singular nouns: `Executive`, `Engineering`, `Platform`.
- Documentation files use **PascalCase** with hyphens between words: `Naming-Conventions.md`.
- Future agent directories should use a concise PascalCase capability name.
- Avoid provider, project, or model names in reusable organization-level names unless the scope is explicitly platform-specific.
- Keep names consistent across directory names, documentation headings, and future machine-readable identifiers.
