# OniRoute Quick Start Guide (Phase P6.D1)

## 30-Second Quick Start

Run your first autonomous swarm engineering request:

```bash
# 1. Build a complete project from natural language prompt
oniroute build real-estate website

# 2. View JSON output report
oniroute build SaaS CRM --json
```

That's it! OniRoute automatically handles:
- Intent Analysis & Smart Defaults
- Workspace & Repository Intelligence
- Skill Discovery & Agent Profile Building
- Swarm Initialization & Project Assembly
- Code Generation, Quality Gate Review, Self-Healing, and Release Certification!
