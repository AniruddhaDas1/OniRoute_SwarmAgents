# Architecture History

OniRoute evolved through explicit, frozen architectural phases:

```text
v0.1  Agent Architecture
  ↓
v0.2  Knowledge Architecture
  ↓
v0.3  Workflow Architecture
  ↓
v0.4  Runtime Foundation
  ↓
ACR-001  Motion Engineering
  ↓
ACR-002  Intelligent Context Optimization Engine
  ↓
v1.0.0  First Stable Release
```

Each phase established a bounded responsibility and retained its decision history. Version 1.0.0 certifies the existing frozen layers; it does not reopen or extend them. Future incompatible architecture work requires an approved Architecture Change Request.
