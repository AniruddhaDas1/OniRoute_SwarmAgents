# Quick Start

After installation, run `oniroute doctor`, `oniroute list workflows`, and `oniroute inspect workflow rest-api-design`. Build a plan with `oniroute plan workflow rest-api-design`; run it with `oniroute run workflow rest-api-design`. The default AI policy is Dry Run. Inspect selection with `oniroute recommend-model --capability reasoning --local`, Tool metadata with `oniroute recommend-tool --capability database`, and governance with `oniroute policy workflow rest-api-design`.
