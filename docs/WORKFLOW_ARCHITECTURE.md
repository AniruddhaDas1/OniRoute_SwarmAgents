# OniRoute Workflow Architecture

OniRoute Workflows are provider-, runtime-, and implementation-independent collaboration contracts. The ecosystem comprises specification, registry, resolution, Official library, governance, and validation. Lifecycle is Draft, Experimental, Reviewed, Verified, Official, Deprecated, Archived, Removed. Registry governs discovery and provenance; resolution follows the unique eight-stage metadata order; governance controls review, promotion, versioning, ownership, deprecation, retirement, and approvals. Every Official Workflow has one Primary Agent and one Primary Sub-Agent. Dependencies reference Workflows, Skills, Packages, Knowledge Sources, or Artifacts. Future extensions must preserve declarative boundaries and require a validated production gap or approved ACR.
