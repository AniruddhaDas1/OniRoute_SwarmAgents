# Provenance Preservation

Normalization must retain an immutable provenance record containing:

- Original author
- Repository or source locator
- Commit, revision, tag, or content digest
- Original version
- Declared license and attribution evidence
- Original file and package path
- Original identifier
- Import timestamp
- Normalization version
- Mapping decisions, warnings, and reviewer or policy context

Canonical metadata is a governed view, not a replacement for source history. Provenance survives version updates, duplicate checks, rejection, quarantine, supersession, and archival. A source that cannot provide sufficient provenance may be admitted only to a review or quarantine state, never silently treated as authoritative.
