## Recommended OniRoute Agents

- Architecture Agent — Evaluate boundaries and reusable contracts.
- Documentation Agent — Assess documentation-related metadata without taking ownership of source content.
- Platform Agent — Review provider and tool compatibility where declared.
- Testing Agent — Define future evidence requirements.

## Recommended OniRoute Sub-Agents

- Architecture review and compatibility-focused sub-agents as applicable.
- Documentation review where documentation claims are present.
- Presentation or frontend sub-agents where communication or interface guidance is declared.

## Normalization Considerations

- Preserve original repository, commit, license, paths, identifiers, and version evidence.
- Map categories and tags to canonical OniRoute values.
- Resolve duplicate IDs, dependencies, context contracts, and Agent compatibility before admission.
- Do not copy source content or infer permissions from repository structure.
