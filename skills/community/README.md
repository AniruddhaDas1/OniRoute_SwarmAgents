# Community Skill Metadata Catalog

This directory contains metadata-only records for nine community Skill repositories. It does not contain copied source files, prompts, Markdown Skills, examples, scripts, packages, or executable content.

## Purpose

The catalog preserves source provenance and provides a review queue for future OniRoute normalization and Registry admission.

## Included Sources

Each repository has `README.md`, `SOURCE.md`, `IMPORT_METADATA.yaml`, and `CATALOG.md`. These records describe purpose, categories, approximate tree-derived Skill counts, domains, strengths, limitations, compatibility recommendations, and normalization considerations.

## Import Readiness

Records are cataloged but not admitted as Skills. License, schema, dependency, compatibility, duplicate, and content-boundary validation remains required. The agent-skills topic is discovery-only.

## Boundaries

No repository contents were copied. No Skills were created, installed, executed, or added to the Registry. The catalog does not implement import, parsing, normalization, validation, or runtime behavior.
