# Skill Versioning

Skills use Semantic Versioning: `MAJOR.MINOR.PATCH`.

- **Major** — incompatible input/output contracts, removed capabilities, or breaking compatibility changes.
- **Minor** — backward-compatible capabilities, optional fields, or expanded compatible context.
- **Patch** — backward-compatible corrections, clarifications, or metadata fixes.

Consumers may rely on the declared major version for compatibility. A compatible-agent or tool change must be assessed against the contract. Version changes require updated provenance and validation timestamps.
