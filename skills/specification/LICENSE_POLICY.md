# Skill License Policy

Every Skill must declare `author`, `organization`, `license`, and `source` metadata. Imported Skills must retain, without alteration:

- Original author
- Repository or source location
- Declared license
- Original path within the source
- Original version

Import acceptance requires a recognizable license, preserved attribution, and confirmation that redistribution and modification are permitted by that license. License uncertainty blocks verification and Official status. OniRoute metadata does not replace the original license.
