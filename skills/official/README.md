# Official Skill Library

This directory contains the Official versioned Skill Library for OniRoute.

## Structure

- `foundation/` — Foundation skills for core engineering operations.
- `frontend/` — Frontend frameworks, components, and layout skills.
- `backend/` — Backend services, APIs, and microservices skills.
- `database/` — Database schemas, migrations, and query skills.
- `devops/` — CI/CD pipelines, containerization, and infrastructure skills.
- `ai/` — LLM integration, prompt design, and AI agent skills.
- `analytics/` — Data analytics, metrics, and telemetry skills.
- `platform/` — Multi-platform runtime and distribution skills.
- `presentation/` — Terminal rendering and user experience skills.
- `security/` — Security rules, governance, and audit skills.
- `motion/` — Motion engineering skills (ACR-001).
