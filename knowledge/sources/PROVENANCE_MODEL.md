# Knowledge Source Provenance

Preserve the following source history:

- Author
- Repository or origin locator
- Commit, branch, tag, revision, or digest
- Declared license
- Import timestamp, when an asset is imported
- Discovery timestamp, when the Source was observed
- Normalization version, when metadata is normalized
- Owner and attribution evidence
- Original path or asset identifier
- Discovery and change-detection evidence

Source provenance is immutable evidence. A later normalized Skill or Package references its Source provenance but does not replace it. Missing provenance lowers trust and blocks validation or admission according to policy.
