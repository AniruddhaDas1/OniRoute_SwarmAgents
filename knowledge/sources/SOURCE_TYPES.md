# Knowledge Source Types

- **GitHub Repository** — public or private repository origin with branches, commits, issues, and releases; trust requires repository identity, pinned revisions, and license evidence.
- **Git Repository** — decentralized repository origin; supports immutable commits but requires host identity, revision capture, and access policy.
- **MCP Server** — future connector origin exposing structured resources or tools; trust requires server identity, protocol policy, and scoped authentication.
- **Local Folder** — filesystem origin for personal or enterprise content; trust requires explicit owner, path policy, snapshot or digest, and local license evidence.
- **HTTP Registry** — future remote catalog or artifact endpoint; trust requires HTTPS, authenticated or signed metadata, and immutable references.
- **OCI Registry** — future digest-addressed artifact registry; trust requires registry identity, signatures, manifests, and license metadata.
- **Enterprise Repository** — organization-controlled source with private governance, retention, and access policy.
- **Personal Repository** — individual-owned source with explicit ownership, consent, license, and review requirements.
- **Future Connectors** — additional origins admitted only through a connector contract and the same trust and provenance gates.

Source type describes origin characteristics; it does not grant trust or imply asset quality.
