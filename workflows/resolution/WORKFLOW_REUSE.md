# Workflow Reuse

Reusable declarations may include **Shared Workflow Modules**, **Referenced Workflows**, **Inherited Workflow Contracts**, **Reusable Approval Blocks**, **Reusable Artifact Blocks**, **Reusable Decision Blocks**, and **Reusable Context Blocks**. Reuse requires compatible versions, explicit references, provenance, and validation of inherited constraints. Reuse never transfers ownership, authorship, approval authority, or accountability; a parent may only add constraints unless an explicit breaking version is declared.
