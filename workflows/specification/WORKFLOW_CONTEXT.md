# Workflow Context

- **Entering Workflow:** declared inputs, constraints, assumptions, and provenance.
- **Between Agents:** only contract-relevant context explicitly permitted for the next participant.
- **Entering Skills:** the minimum context a Skill may receive, subject to its own contract.
- **Returned:** outputs, decisions, artifacts, evidence, and provenance promised by the contract.
- **Discarded:** sensitive, unnecessary, expired, or explicitly non-retained information.
- **Retained:** context required for traceability, audit, or downstream obligations.
- **Provenance:** source, owner, timestamp, transformation, authorization, and integrity status.

Context rules must identify data minimization, authority, retention, and handling constraints without prescribing transport or storage technology.
