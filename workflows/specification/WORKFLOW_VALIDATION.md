# Workflow Validation

Validation checks metadata completeness and shape; owner, maintainer, and author accountability; participant identity and boundaries; dependency kind, version, provenance, and compatibility; lifecycle/status consistency; semantic version; artifact declarations; context entry, exchange, retention, discard, and provenance rules; decision points and approval gates; security classification; license/source; and success criteria. A Workflow is **Valid** only when all required checks pass and evidence is recorded. Validation is documentation governance, not execution testing.
