# Workflow Tagging

Tags are normalized, non-authoritative metadata for discovery. Tags should be lowercase, concise, stable, non-duplicative, and based on declared scope, capabilities, participants, artifacts, or constraints. Tags must not contradict the canonical category, imply unvalidated compatibility, encode secrets, or substitute for lifecycle, classification, trust, security, or approval fields.

Tag additions and removals must preserve review history when they materially change discoverability.
