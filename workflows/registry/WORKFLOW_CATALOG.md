# Workflow Catalog

The catalog is the governed view of admitted registry records. It organizes records by canonical identity and version, then exposes category, classification, lifecycle, ownership, compatibility, artifacts, dependencies, quality, trust, and provenance.

One Workflow ID may have multiple version records, but each ID and version pair must be unique. Deprecated, Archived, Removed, rejected, or superseded records remain distinguishable from active records. Catalog inclusion never creates a Workflow instance or grants execution authority.
