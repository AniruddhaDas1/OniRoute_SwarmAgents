# Workflow Search

Search is defined only as matching and filtering registry metadata. Searchable fields include identity, names, descriptions, categories, classifications, tags, capabilities, participants, compatibility, artifacts, dependencies, lifecycle, validation, trust, quality, security classification, owner, source, and license.

Search results must identify the matched metadata and preserve version and provenance. This document defines no query language, ranking algorithm, index technology, API, user interface, or search implementation.
