# Package Trust

- **Official** — governed and maintained by OniRoute authority.
- **Verified** — provenance, license, integrity, dependencies, and compatibility passed checks.
- **Community** — externally maintained with transparent provenance.
- **Enterprise** — governed by an organization under documented controls.
- **Personal** — individual-owned and explicitly scoped.
- **Experimental** — restricted evaluation with declared risk.
- **Unknown** — insufficient evidence and ineligible for normal installation.

Trust is separate from lifecycle, validation, quality, and Source trust.
