# Package Versioning

Packages use Semantic Versioning.

- **Major** changes break content, dependency, installation, or compatibility contracts.
- **Minor** changes add backward-compatible content or compatibility.
- **Patch** changes correct metadata, documentation, validation evidence, or compatible defects.

Version history is immutable. Package and contained-asset versions remain independent and must both be declared. Minimum and maximum OniRoute versions constrain compatibility.
