# Package Types

- **Core Package** — OniRoute-governed foundational capabilities.
- **Community Package** — externally maintained and community-governed.
- **Enterprise Package** — organization-controlled with private policy and distribution.
- **Personal Package** — individual-owned and locally scoped.
- **Extension Package** — adds optional capability to an existing Package or platform.
- **Experimental Package** — restricted evaluation with declared risk.
- **Template Package** — reusable templates and metadata without execution authority.
- **Domain Package** — capabilities grouped around a bounded domain.

Package type describes governance and intent, not trust, validation, or lifecycle state.
