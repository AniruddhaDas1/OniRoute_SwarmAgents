# Universal Package Specification

An OniRoute Package is a versioned, provenance-preserving distribution boundary that groups reusable metadata and assets without changing their ownership.

## Supported Contents

- Skills
- Future Workflow definitions
- Knowledge references
- Prompt templates
- Adapter definitions
- Configuration
- Assets
- Examples
- Tests
- Documentation
- Metadata

Every content entry must declare type, path or reference, version where relevant, license, integrity evidence, and compatibility. Content presence does not authorize execution.
