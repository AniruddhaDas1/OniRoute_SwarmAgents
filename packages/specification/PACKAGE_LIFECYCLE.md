# Package Lifecycle

- **Draft** — metadata and contract under authoring.
- **Experimental** — restricted evaluation with declared risk.
- **Verified** — passed metadata, integrity, security, dependency, and compatibility checks.
- **Official** — approved and maintained by OniRoute authority.
- **Installed** — present in a future local Package store; installation does not imply execution.
- **Deprecated** — retained for migration with successor guidance.
- **Archived** — preserved for history and excluded from normal use.
- **Removed** — withdrawn from active distribution while audit evidence is retained.

Transitions require recorded evidence, authority, timestamps, and policy version.
