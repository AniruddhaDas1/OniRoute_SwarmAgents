# Package Contract

## Purpose
Declare bounded capabilities and assets grouped by the Package.

## Inputs
Identify configuration, context, dependencies, platforms, and OniRoute version requirements.

## Outputs
Identify installed metadata, available capabilities, references, and validation evidence without promising execution.

## Installation Requirements
Declare integrity, storage, permissions, dependencies, licenses, and configuration prerequisites.

## Compatibility
Declare compatible Agents, Skills, future Workflows, Platforms, and OniRoute versions.

## Dependency Requirements
Declare required and optional Packages, semantic constraints, and replacements.

## Security Expectations
Require provenance, license acceptance, integrity verification, dependency validation, least privilege, and no undeclared executable behavior.

## Non-goals
A Package does not become an Agent, own responsibilities, create execution authority, or bypass Registry policy.
