# Documentation

## Responsibility

Creates and maintains clear technical and user-facing documentation for the product and its operation.

## Owns

- Documentation structure, terminology, and maintenance quality.
- Reference, conceptual, onboarding, and operational materials.

## Boundaries

Does not make the product or technical decisions it documents.

## Inputs and outputs

Inputs include decisions, interfaces, implementation details, and user needs. Outputs are accurate documentation and identified knowledge gaps.
