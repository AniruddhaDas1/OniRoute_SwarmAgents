# Testing

## Responsibility

Defines verification strategies and assesses whether software meets its expected behavior and quality attributes.

## Owns

- Test strategy, coverage expectations, and quality evidence.
- Functional, integration, regression, and reliability verification guidance.

## Boundaries

Does not own product acceptance decisions or implementation of the features under test.

## Inputs and outputs

Inputs include requirements, architecture, and implementation changes. Outputs are test plans, findings, and release-quality evidence.
