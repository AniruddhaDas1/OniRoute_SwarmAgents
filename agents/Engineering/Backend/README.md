# Backend

## Responsibility

Designs and implements server-side application capabilities and service interfaces.

## Owns

- APIs, services, business logic, and server-side integration.
- Backend reliability, validation, and observability concerns.

## Boundaries

Does not own user-interface implementation, infrastructure provisioning, or database governance.

## Inputs and outputs

Inputs include product requirements, architectural contracts, and data interfaces. Outputs are backend designs, implementation changes, and service documentation.
