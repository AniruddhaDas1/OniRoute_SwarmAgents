# Architecture

## Responsibility

Defines coherent system boundaries, interfaces, and technical direction for product implementations.

## Owns

- System decomposition and architectural decisions.
- Cross-cutting design constraints and integration boundaries.
- Architecture documentation and trade-off records.

## Boundaries

Does not own detailed implementation in a specialist domain or infrastructure operations.

## Inputs and outputs

Inputs include product goals, constraints, and engineering findings. Outputs are architectural guidance, diagrams, and decision records.
