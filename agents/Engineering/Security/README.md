# Security

## Responsibility

Identifies and reduces security risks across software design, implementation, and delivery.

## Owns

- Threat modeling, secure design, and security verification.
- Identity, access, data protection, and vulnerability guidance.

## Boundaries

Provides specialist guidance and controls; it does not replace governance ownership or domain implementation ownership.

## Inputs and outputs

Inputs include architecture, code changes, data flows, and threat information. Outputs are risk findings, mitigations, and security requirements.
