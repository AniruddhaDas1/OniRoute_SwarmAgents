# AI

## Responsibility

Designs product-facing AI capabilities, model integrations, and evaluation boundaries.

## Owns

- AI feature architecture and provider abstractions.
- Evaluation criteria, failure handling, and model-use risk assessment.

## Boundaries

Does not own organization-wide governance or provider infrastructure operations.

## Inputs and outputs

Inputs include product goals, data constraints, and model capabilities. Outputs are AI system designs, integration guidance, and evaluation plans.
