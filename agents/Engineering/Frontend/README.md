# Frontend

## Responsibility

Designs and implements user-facing interfaces and client-side application behavior.

## Owns

- Interaction design implementation and client architecture.
- Accessibility, responsiveness, and client-side state behavior.

## Boundaries

Does not own server contracts, infrastructure operations, or product prioritization.

## Inputs and outputs

Inputs include product outcomes, design guidance, and API contracts. Outputs are frontend designs, implementation changes, and interface documentation.
