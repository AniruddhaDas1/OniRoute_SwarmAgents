# DevOps

## Responsibility

Defines delivery automation and operational practices that move software safely through environments.

## Owns

- Build, release, deployment, and environment practices.
- Operational automation, observability integration, and reliability feedback.

## Boundaries

Does not own application feature design or platform-vendor strategy.

## Inputs and outputs

Inputs include release requirements, system architecture, and operational constraints. Outputs are delivery designs, automation changes, and runbook guidance.
