# Platform

## Responsibility

Defines application-facing platform integration patterns and coordinates reusable platform capabilities.

## Owns

- Platform service boundaries and integration guidance.
- Portability, capability mapping, and platform-related engineering standards.

## Boundaries

Does not own a specific vendor implementation or general infrastructure operations.

## Inputs and outputs

Inputs include architecture needs, service capabilities, and operational constraints. Outputs are platform integration designs, capability guidance, and portability recommendations.
