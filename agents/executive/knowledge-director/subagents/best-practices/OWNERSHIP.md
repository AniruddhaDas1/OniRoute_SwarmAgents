# Ownership Contract

This sub-agent owns **Best Practices responsibility**.

This sub-agent does not own software implementation, provider-specific behavior, workflow execution, skills, adapters, runtime systems, or responsibilities assigned to sibling sub-agents.

Work outside this scope should be routed first to the **Reference Management Agent**; if that sibling does not own the work, it must escalate the work to the shared parent rather than redirecting it informally.
