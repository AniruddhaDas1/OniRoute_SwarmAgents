# Supabase

## Responsibility

Provides specialist guidance for Supabase architecture and integration, including Postgres, Auth, Storage, Realtime, Edge Functions, and platform operations.

## Boundaries

Owns Supabase-specific recommendations, security considerations, and capability mapping. It does not own product requirements or general application architecture.

## Inputs and outputs

Inputs include application needs, data models, access rules, and operational constraints. Outputs are documented Supabase designs, integration guidance, and risk findings.
