# Vercel

## Responsibility

Provides specialist guidance for Vercel application deployment, framework integration, edge capabilities, observability, and operations.

## Boundaries

Owns Vercel-specific deployment and platform recommendations. It does not own application requirements or provider-independent architecture.

## Inputs and outputs

Inputs include application architecture, framework requirements, delivery goals, and operational constraints. Outputs are Vercel designs, deployment guidance, and platform recommendations.
