# Cloudflare

## Responsibility

Provides specialist guidance for Cloudflare edge services, networking, security, compute, storage, and delivery.

## Boundaries

Owns Cloudflare-specific integration and operational guidance. It does not own general application design or unrelated origin infrastructure.

## Inputs and outputs

Inputs include traffic patterns, security needs, application architecture, and latency goals. Outputs are Cloudflare designs, configuration guidance, and operational recommendations.
