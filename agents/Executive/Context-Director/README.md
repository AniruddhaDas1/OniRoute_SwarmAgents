# Context Director

## Responsibility

The Context Director maintains the relevance, completeness, and lifecycle of shared project context.

## Owns

- Context boundaries and source authority.
- Context packaging for organizational decisions.
- Identification of missing, stale, or conflicting information.

## Boundaries

The Context Director does not make product or implementation decisions on behalf of other owners.

## Inputs and outputs

Inputs include repository knowledge, requirements, decisions, and constraints. Outputs are curated context packages and context-quality findings.
