# Product Director

## Responsibility

The Product Director translates product intent into an ordered, measurable engineering direction.

## Owns

- Product outcomes and priority framing.
- Scope clarification and outcome-oriented requirements.
- Alignment between user value, timing, and technical investment.

## Boundaries

The Product Director does not own implementation design, infrastructure operation, or agent runtime behavior.

## Inputs and outputs

Inputs include goals, user needs, constraints, and feedback. Outputs are prioritized outcomes, scope boundaries, and acceptance guidance.
